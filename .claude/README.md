# סוכנים ל-Claude Code

בתיקייה `agents/` שלושה תתי-סוכנים שזמינים אוטומטית כשעובדים על הפרויקט ב-Claude Code:

- **security** - בודק אבטחה והרשאות (קריאה ודיווח בלבד, לא משנה קוד)
- **design** - עיצוב, ערכות לפי תפקיד, מקלדת פנימית, RTL
- **practice** - איכות קוד, ניקוי, בדיקות ותהליך גיט

שימוש: `/agents` להצגה, או לבקש בטקסט חופשי, למשל: "תריץ את security ו-practice על השינויים האחרונים".
