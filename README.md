# הקופה המשפחתית

אפליקציית קופה בעברית: רושמים כמה כסף חייבים בבית. כל בן משפחה נכנס עם קוד סודי משלו, והנתונים נשמרים בשרת **Convex** ומתעדכנים בזמן אמת בכל המכשירים.

## מה אפשר לעשות
**ילדים** (מסך פשוט עם כפתורים גדולים):
- לבחור את עצמם ולהיכנס עם קוד בן 4 ספרות (בפעם הראשונה בוחרים קוד בעצמם)
- לרשום "אני חייב/ת כסף" או "חייבים לי כסף"
- לסמן "שילמתי" / "קיבלתי", החזר חלקי או הכול
- לראות רק את הדברים שקשורים אליהם, ולבטל רישום בטעות תוך 10 דקות

**הורים** (בנוסף):
- לראות את כל המשפחה: יתרות, חובות פתוחים והיסטוריה מלאה
- להוסיף ולהסיר בני משפחה, לקבוע או לאפס קוד סודי
- למחוק כל רשומה, גיבוי לקובץ, והעברת נתונים מהגרסה הישנה (localStorage)

ההרשאות נאכפות בשרת (`convex/`), לא רק בממשק. הקוד הסודי נשמר כגיבוב בלבד, וחמישה ניסיונות שגויים נועלים את הפרופיל לדקה.

## מראה לפי תפקיד, נוער ומצב חברים
- **הורים:** מראה רגוע ומקצועי. נפתחים על לשונית "המשפחה": אישורים בראש (ותג עם מספר הממתינים), אחריהם כסף, אנשים, הגדרות המשפחה ו"אזור מסוכן" (מחיקת הקופה).
- **ילדים:** הממשק הצבעוני והפשוט כמו קודם.
- **נוער (תפקיד חדש):** ערכה כהה ועכשווית. הורה קובע תפקיד "נער/ה" ב"בני המשפחה" (או מוסיף ככה מהתחלה).
- **מצב חברים:** נער/ה מבקש/ת אישור, והורה מאשר/ת וקובע/ת את המייל שלהם (`friends:approveAccess`). אחרי האישור מוסיפים חברים לפי מייל (גם ממשפחות אחרות, בתנאי שלחבר/ה יש מצב חברים). בקשת חברות צריכה אישור של הצד השני. כל חוב או החזר בין חברים ממתין לאישור של החבר/ה השני/ה ולא נספר לפני כן. עד 500 ש"ח לרשומה. הורים רואים (לקריאה בלבד) מה הנער/ה רושמים, ויכולים לכבות את המצב בכל רגע.

## אישור הורה, התראות ודמי כיס קבועים
- **אישור הורה:** כל רשומה שילד/ה יוצר/ת (חוב או החזר) מקבלת סטטוס "ממתין לאישור" ולא נספרת ביתרות. הורה מאשר או דוחה בלחיצה בראש לשונית "המשפחה". ילד/ה יכול/ה לבטל רשומה שממתינה בכל שלב.
- **התראות (Web Push):** הורה מקבל התראה כשילד רושם משהו לאישור. מי שמישהו רשם עליו חוב מקבל התראה, וגם מי שרשומה שלו אושרה או נדחתה. פעם בשבוע (ראשון בבוקר) הורים מקבלים תזכורת על חובות פתוחים שלא זזו שבועיים. כל משתמש מפעיל התראות מ"⚙️ החשבון שלי" (בכותרת). ב-iPhone ההתראות עובדות רק אחרי "הוספה למסך הבית".
- **דמי כיס קבועים:** בלשונית "המשפחה" הורה מגדיר רישום חוזר (שבועי או חודשי). משימה יומית בשרת (`convex/crons.ts`) יוצרת את החוב בתאריך המתאים ומשלימה רישומים שהוחמצו.

### הגדרת התראות בשרת (פעם אחת)
ב-Convex Dashboard, בהגדרות Environment Variables של ה-production, מוסיפים:
- `VAPID_PUBLIC_KEY` - אותו מפתח שמופיע ב-`public/config.js` (`window.VAPID_PUBLIC_KEY`)
- `VAPID_PRIVATE_KEY` - המפתח הפרטי (סודי, לא נכנס לגיט)
- `VAPID_SUBJECT` - למשל `mailto:כתובת-האימייל-שלך`

בלי המשתנים האלה האפליקציה עובדת כרגיל, פשוט בלי התראות. מפתחות חדשים: `npx web-push generate-vapid-keys`.

## החשבון שלי
כפתור ⚙️ בכותרת פותח את ההגדרות האישיות: התראות, שינוי קוד סודי, מייל לשחזור (הורים), בקשת מעבר לנוער (ילדים), תנאי שימוש ופרטיות, ויציאה.

## הפעלה ראשונה (פעם אחת)
```bash
npm install
npx convex dev        # מתחבר לחשבון Convex, יוצר פרויקט ופורס את convex/ (ויוצר convex/_generated)
```
1. את הכתובת שמודפסת (`https://....convex.cloud`) מדביקים ב-`public/config.js` בשורה `window.CONVEX_URL`.
2. לפריסה קבועה: `npx convex deploy`, ובקובץ `public/config.js` שמים את כתובת ה-production.
3. ב-GitHub: Settings > Pages > Source: **GitHub Actions**. אחרי זה כל push ל-`main` בונה ופורס את האתר (`.github/workflows/pages-deploy.yml`).

פיתוח מקומי: `npm run web:dev` (Vite) ובמקביל `npm run dev` (Convex). בנייה: `npm run build`.

## הרבה משפחות
כל משפחה היא קופה נפרדת. הורה מקים משפחה חדשה ("אני הורה ורוצה להקים קופה חדשה") ומקבל שני קודי הצטרפות בלשונית "המשפחה" (בקטע "בני המשפחה"):
- **קוד ילדים**: מי שמקליד אותו במסך הפתיחה ובוחר "אני חדש/ה" מצטרף בתור ילד/ה.
- **קוד הורים**: להורה השני. מצטרף בתור הורה.

הקוד קובע את התפקיד, ולכן ילד שפותח ראשון לא יכול להפוך להורה. כל השאילתות והמוטציות בשרת מסוננות לפי המשפחה של המחובר/ת. אפשר להחליף קוד, לשנות שם משפחה ולמחוק את הקופה כולה.

**נתונים מהגרסה של משפחה אחת:** הורה מהגרסה הישנה נכנס פעם אחת מהכרטיס "כבר משתמשים בקופה?" במסך הפתיחה (או שהוא כבר מחובר). הקופה הקיימת עוברת למשפחה עם קודים. ילדים נכנסים אחר כך עם קוד הילדים.

הגבלות קצב (בקובץ `convex/lib.ts`): ניחושי קוד שגויים וקצב יצירת משפחות.

מומלץ להוסיף ל-git גם את התיקייה `convex/_generated` אחרי ההרצה הראשונה.

## מבנה
- `index.html`, `vite.config.js` - נקודת הכניסה של Vite
- `src-react/` - הממשק ב-React: `App.jsx` (ניתוב מסכים, לשוניות, #hash), `components/` (`auth/` מסכי כניסה, `family/` רכיבי לשונית המשפחה, `account/` חלונות החשבון, `sheets/` שדות משותפים), `lib/` (חישובי חובות, `api.js` קריאות לשרת, `useRun`, `helpers.js`, `push.js`)
- `src-react/state/` - מצב כניסה משותף (`state.js`) והלוגיקה של מסכי הכניסה (`auth.js`)
- `public/` - `style.css`, `config.js`, `sw.js`, manifest, תנאי שימוש ופרטיות (מועתקים כמו שהם ל-`dist`)
- `convex/` - סכמה, כניסה והצטרפות (`auth.ts`), נתונים (`data.ts`), רשומות (`entries.ts`), אנשים (`people.ts`), משפחה (`family.ts`), ייבוא (`admin.ts`), כלים משותפים (`lib.ts`)
