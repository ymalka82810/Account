# הקופה המשפחתית

אפליקציית קופה בעברית: רושמים כמה כסף חייבים בבית. כל בן משפחה נכנס עם קוד סודי משלו, והנתונים נשמרים בשרת **Convex** ומתעדכנים בזמן אמת בכל המכשירים.

## מה אפשר לעשות
**ילדים** (מסך פשוט עם כפתורים גדולים):
- לבחור את עצמם ולהיכנס עם קוד בן 4 ספרות (בפעם הראשונה בוחרים קוד בעצמם)
- לרשום "אני חייב/ת כסף" או "חייבים לי כסף"
- לסמן "שילמתי" / "קיבלתי", החזר חלקי או הכול
- לראות רק את הדברים שקשורים אליהם, ולבטל רישום בטעות תוך 10 דקות

**הורים** (בנוסף):
- לראות את כל המשפחה: יתרות, חובות פתוחים והיסטוריה מלאה
- להוסיף ולהסיר בני משפחה, לקבוע או לאפס קוד סודי
- למחוק כל רשומה, גיבוי לקובץ, והעברת נתונים מהגרסה הישנה (localStorage)

ההרשאות נאכפות בשרת (`convex/`), לא רק בממשק. הקוד הסודי נשמר כגיבוב בלבד, וחמישה ניסיונות שגויים נועלים את הפרופיל לדקה.

## מראה לפי תפקיד, נוער ומצב חברים
- **הורים:** מראה רגוע ומקצועי. נפתחים על לשונית "המשפחה": אישורים בראש (ותג עם מספר הממתינים), יתרות, חובות פתוחים ומה שהנוער רושם. לשונית "ניהול" נפרדת מכילה בני משפחה, קודי הצטרפות, דמי כיס קבועים, גיבוי, הגדרות ו"אזור מסוכן" (מחיקת הקופה).
- **ילדים:** הממשק הצבעוני והפשוט כמו קודם.
- **נוער (תפקיד חדש):** ערכה כהה ועכשווית. הורה קובע תפקיד "נער/ה" ב"בני המשפחה" (או מוסיף ככה מהתחלה).
- **מצב חברים:** נער/ה מבקש/ת אישור, והורה מאשר/ת וקובע/ת את המייל שלהם (`friends:approveAccess`). אחרי האישור מוסיפים חברים לפי מייל (גם ממשפחות אחרות, בתנאי שלחבר/ה יש מצב חברים). בקשת חברות צריכה אישור של הצד השני. כל חוב או החזר בין חברים ממתין לאישור של החבר/ה השני/ה ולא נספר לפני כן. עד 500 ש"ח לרשומה. הורים רואים (לקריאה בלבד) מה הנער/ה רושמים, ויכולים לכבות את המצב בכל רגע.

## אישור הורה, התראות ודמי כיס קבועים
- **אישור הורה:** כל רשומה שילד/ה יוצר/ת (חוב או החזר) מקבלת סטטוס "ממתין לאישור" ולא נספרת ביתרות. הורה מאשר או דוחה בלחיצה בראש לשונית "המשפחה". ילד/ה יכול/ה לבטל רשומה שממתינה בכל שלב.
- **התראות (Web Push):** הורה מקבל התראה כשילד רושם משהו לאישור. מי שמישהו רשם עליו חוב מקבל התראה, וגם מי שרשומה שלו אושרה או נדחתה. פעם בשבוע (ראשון בבוקר) הורים מקבלים תזכורת על חובות פתוחים שלא זזו שבועיים. כל משתמש מפעיל התראות מ"⚙️ החשבון שלי" (בכותרת). ב-iPhone ההתראות עובדות רק אחרי "הוספה למסך הבית".
- **דמי כיס קבועים:** בלשונית "ניהול" הורה מגדיר רישום חוזר (שבועי או חודשי). משימה יומית בשרת (`convex/crons.ts`) יוצרת את החוב בתאריך המתאים ומשלימה רישומים שהוחמצו.

### הגדרת התראות בשרת (פעם אחת)
ב-Convex Dashboard, בהגדרות Environment Variables של ה-production, מוסיפים:
- `VAPID_PUBLIC_KEY` - אותו מפתח שמופיע ב-`public/config.js` (`window.VAPID_PUBLIC_KEY`)
- `VAPID_PRIVATE_KEY` - המפתח הפרטי (סודי, לא נכנס לגיט)
- `VAPID_SUBJECT` - למשל `mailto:כתובת-האימייל-שלך`

בלי המשתנים האלה האפליקציה עובדת כרגיל, פשוט בלי התראות. מפתחות חדשים: `npx web-push generate-vapid-keys`.

## מיקום, מטבע ושערי המרה
- **מיקום ומטבע:** בלשונית "ניהול" > "הגדרות המשפחה" הורה בוחר מדינת מגורים (שקובעת את המטבע שלה) ואת המטבע הראשי של המשפחה. ברירת מחדל: ישראל, שקלים.
- **חוב במטבע אחר:** ברישום חוב אפשר לבחור מטבע (למשל 100 דולר). החוב נשמר במטבע שלו, ובכל היתרות הוא מוצג לפי השווי שלו היום במטבע הראשי.
- **תשלום:** החזר נרשם תמיד במטבע הראשי. על חוב במטבע אחר הוא מומר לפי השער ברגע התשלום, והשער נשמר בהחזר (`fx`) כך שהחישוב לא משתנה בדיעבד.
- **שערים:** `convex/fx.ts` מביא שערים מ-open.er-api.com (גיבוי: frankfurter.app, הבנק האירופי) כל 3 שעות ושומר בטבלה `fxRates`. בלי מפתח API.
- רשומות מלפני הפיצ'ר (בלי `currency`) נחשבות שקלים. בין חברים הכול נשאר בשקלים.

## החשבון שלי
כפתור ⚙️ בכותרת פותח את ההגדרות האישיות: התראות, שינוי קוד סודי, מייל לשחזור (הורים), בקשת מעבר לנוער (ילדים), תנאי שימוש ופרטיות, ויציאה.

## הפעלה ראשונה (פעם אחת)
```bash
npm install
npx convex dev        # מתחבר לחשבון Convex, יוצר פרויקט ופורס את convex/ (ויוצר convex/_generated)
```
1. את הכתובת שמודפסת (`https://....convex.cloud`) מדביקים ב-`public/config.js` בשורה `window.CONVEX_URL`.
2. לפריסה קבועה: `npx convex deploy`, ובקובץ `public/config.js` שמים את כתובת ה-production.
3. ב-GitHub: Settings > Pages > Source: **GitHub Actions**. אחרי זה כל push ל-`main` בונה ופורס את האתר (`.github/workflows/pages-deploy.yml`).

פיתוח מקומי: `npm run web:dev` (Vite) ובמקביל `npm run dev` (Convex). בנייה: `npm run build`.

## הרבה משפחות
כל משפחה היא קופה נפרדת. הורה מקים משפחה חדשה ("אני הורה ורוצה להקים קופה חדשה") ומקבל **קוד הצטרפות אחד** בלשונית "ניהול".
כל מי שמקליד אותו במסך הפתיחה ובוחר "אני חדש/ה" מצטרף בתור ילד/ה. הורה משנה תפקיד ב"בני המשפחה" (ילד/ה, נער/ה או הורה), וכל שינוי כזה דורש **טביעת אצבע או זיהוי פנים** (ראו למטה). כך ילד שמקבל את הקוד לא יכול להפוך להורה בעצמו. כל השאילתות והמוטציות בשרת מסוננות לפי המשפחה של המחובר/ת. אפשר להחליף קוד, לשנות שם משפחה ולמחוק את הקופה כולה.

**נתונים מהגרסה של משפחה אחת:** הורה מהגרסה הישנה נכנס פעם אחת מהכרטיס "כבר משתמשים בקופה?" במסך הפתיחה (או שהוא כבר מחובר). הקופה הקיימת עוברת למשפחה עם קודים. בני המשפחה נכנסים אחר כך עם קוד המשפחה.

הגבלות קצב (בקובץ `convex/lib.ts`): ניחושי קוד שגויים וקצב יצירת משפחות.

מומלץ להוסיף ל-git גם את התיקייה `convex/_generated` אחרי ההרצה הראשונה.

## אימות ביומטרי לשינוי תפקיד
שינוי תפקיד (וגם הוספת בן משפחה ישר בתור נער/ה או הורה) מאושר בטביעת אצבע או בזיהוי פנים של ההורה, והשרת בודק זאת (`convex/biometric.ts`), לא רק הממשק:
- **באתר:** WebAuthn עם המאמת של המכשיר (`userVerification: required`). השרת בודק חתימה, אתגר חד-פעמי שקשור בדיוק לשינוי, מקור (`https://ymalka82810.github.io`) ודגל "משתמש אומת".
- **באפליקציה (APK):** הפלאגין `android-plugin/BiometricAuthPlugin.java` מציג BiometricPrompt שמאפשר זיהוי פנים או טביעת אצבע (`BIOMETRIC_WEAK`, כי זיהוי הפנים ברוב מכשירי האנדרואיד מסווג כ"חלש"), ואחרי הצלחה חותם על האתגר עם מפתח Keystore שלא יוצא מהאפליקציה.
- רישום מכשיר חדש נעשה פעם אחת לכל מכשיר ודורש את הקוד הסודי של ההורה.
- טביעת האצבע עצמה לא יוצאת מהמכשיר. בשרת נשמר רק מפתח ציבורי.

## אייקון לפי מטבע
האייקון מציג את סמל המטבע של המשפחה (₪ בישראל, $ בארה"ב, € באירופה וכו'). אם למשפחה לא הוגדר מיקום, או לפני כניסה - המטבע האחרון שנשמר במכשיר, או לפי המיקום של המכשיר (אזור הזמן ואז השפה). אם המיקום לא ידוע - דולר.
- **באתר:** ה-favicon מתחלף (`src-react/lib/appIcon.js`). אייקון של PWA שכבר הותקן לא מתעדכן - זו מגבלה של הדפדפן.
- **באפליקציה (APK):** לכל מטבע יש `activity-alias` עם אייקון וקטורי (`android-plugin/apply-currency-icons.py` רץ בבנייה), והפלאגין `AppIconPlugin.java` מפעיל את המתאים כשהאפליקציה יוצאת לרקע.
- סמלי המטבע שמורים כקווי מתאר ב-`assets/currency-icons.json`. מוסיפים מטבע ב-`scripts/gen-currency-icons.py` ומריצים אותו מחדש. הדירהם (הסמל החדש מ-2025, עוד לא בגופנים) מצויר שם ידנית. מטבע לא מוכר מקבל דולר.

## מבנה
- `index.html`, `vite.config.js` - נקודת הכניסה של Vite
- `src-react/` - הממשק ב-React: `App.jsx` (ניתוב מסכים, לשוניות, #hash) ו-`components/` מחולק לפי מקום באפליקציה:
  - `home/`, `friends/`, `history/` - הלשוניות של ילדים ונוער
  - `family/` - לשונית המשפחה (הורים): אישורים, יתרות, חובות פתוחים, מה שהנוער רושם
  - `manage/` - לשונית הניהול (הורים): בני משפחה, קודים, דמי כיס קבועים, גיבוי, העברה מהגרסה הישנה ואזור מסוכן
  - `entries/` - רישום ורשימות משותפות (`EntryFlow`, `EntriesList`, `PendingCards`, `DebtLines`)
  - `account/` - "החשבון שלי", `auth/` - מסכי כניסה, `shared/` - `Sheet`, `Toast`, `AsyncButton`, שדות משותפים
- `src-react/lib/` - חישובי חובות (`computations.js`), `api.js`, `useRun`, `helpers.js`, `push.js`
- `src-react/state/` - מצב משותף (`state.js`, `appContext.js`) ולוגיקת מסכי הכניסה (`auth.js`)
- `public/` - `style.css`, `config.js`, `sw.js`, manifest, תנאי שימוש ופרטיות (מועתקים כמו שהם ל-`dist`)
- `convex/` - סכמה, כניסה והצטרפות (`auth.ts`), נתונים (`data.ts`), רשומות (`entries.ts`), אנשים (`people.ts`), משפחה (`family.ts`), ייבוא (`admin.ts`), כלים משותפים (`lib.ts`)
