# הקופה המשפחתית

אפליקציית קופה פשוטה בעברית: רושמים כמה כסף הורים חייבים לילדים, וכמה הילדים חייבים זה לזה (או להורים).

## מה אפשר לעשות
- להוסיף בני משפחה (הורים וילדים)
- לרשום חוב חדש, החזר חלקי או סגירת חוב מלאה
- לראות מי חייב למי, כשהחובות ההדדיים מקוזזים אוטומטית
- לראות יתרה לכל אדם
- היסטוריה מלאה, גיבוי ושחזור לקובץ

## הרצה
אין צורך בהתקנה. פותחים את `index.html` בדפדפן, או מפעילים GitHub Pages על הענף `main`.
הנתונים נשמרים במכשיר בלבד (localStorage). מומלץ לשמור גיבוי מדי פעם מלשונית "היסטוריה".
